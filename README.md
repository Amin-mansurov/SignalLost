# Personal Journal SignaLlost — Sci-Fi Terminal Journal Game

A story-driven terminal game written in Python where you play as the last active archivist aboard the deep-space vessel **Auriga**.
Manage your journal, uncover the mystery behind the signal, and decide the fate of humanity.

## 🎓 Academic Project

This game was created as an assignment project for Multimedia University (MMU).  
The project focuses on interactive storytelling, Python programming fundamentals, file handling, and terminal-based user interaction.

---

## 🚀 Features

* Interactive sci-fi story
* Typewriter-style text effects
* Journal system with:

  * Create entries
  * Read entries
  * Update entries
  * Delete entries
* Multiple story stages:

  * Opening
  * Main Game
  * Mid Game
  * Final Ending
* Multiple endings based on player decisions
* Lightweight and fully terminal-based

## 🎮 Gameplay

### Main Menu

```text
1. Replay the final moments of the signal
2. Check the crew manifest
3. Open your personal journal
4. Reboot the ship’s AI core
5. Decrypt a corrupted signal fragment
6. Read your Final Orders from Command
```

As you progress, new choices unlock and the story evolves.

---

## 🧠 Journal System

The journal acts as both:

* A save of your memories
* A storytelling mechanic

Entries are stored in the `PersonalJournal` file using this format:

```text
[1] "Example entry"
[2] "Another memory"
```
